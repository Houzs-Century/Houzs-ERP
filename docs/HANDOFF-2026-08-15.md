## 6. Three traps this session paid for, that are not in any gate

1. **`git stash pop` with a clean tree pops SOMEONE ELSE'S stash.** `git stash`
   on a clean tree saves nothing, so the following `pop` restored an unrelated
   entry from another branch and conflicted a file. Nothing was lost — a
   conflicted pop keeps the stash — but check `git stash list` before either.

2. **`echo "pushed"` after a `git push` prints on failure too.** A push was
   rejected as non-fast-forward and the echo still claimed success. Verify by
   re-reading the remote: `git fetch && [ "$(git rev-parse HEAD)" = "$(git rev-parse @{u})" ]`.

3. **A shell ate a `\b` and invalidated a red proof.** A guard was "proven red"
   against a mutation that never applied as intended; the guard would have missed
   the real thing. Apply proof mutations by EDITING THE FILE, never through a
   shell one-liner, and make the mutation script exit non-zero if the
   replacement did not apply.
