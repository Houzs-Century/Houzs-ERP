## 1. BLOCKED — read this first

**The delta cannot start until a fresh AutoCount snapshot exists.** The committed
one is `2026-08-29` (`backend/scripts/data/*.gz`, tracked in git).

`export-ac-reimport.py` fails with `Login failed for user 'sa2'`.

**What was measured (do not re-derive this):**

- `sa2` is **healthy** — `is_disabled 0`, `IsLocked 0`, `IsExpired 0`, read on the
  host with Windows auth. So the password we hold is simply **wrong**; nothing was
  changed or locked, and the owner did not change it.
- The 5-byte scratchpad `.ac-cred` is not the real password.
- **The `data/*.gz` mtimes are NOT evidence an export ran** — they are tracked in
  git, so the timestamp is a checkout artifact. An earlier claim in this session
  that "the export succeeded on 09-02" was retracted for exactly this reason.

**Two ways forward, either unblocks everything:**

**A — the owner supplies the password.** He writes it into the file the exporter
reads (`AC_CRED_FILE`), himself. It must never pass through chat, be echoed, or be
written into a repo file. Then the three exporters run unchanged from the dev
machine — the lowest-risk path, because those exporters are already proven.

**B — `bcp` on the host, no password at all.** The host has `sqlcmd` and
`bcp.exe`; Windows auth opens the book locally with no credential. Dump the raw
rows there, transfer them back, and do the shaping on the dev machine.
**Keep the shaping in ONE place** — re-deriving the exporters' queries by hand is
the "second copy that drifts" trap this repo has paid for repeatedly.

**Getting onto the host:** AnyDesk **480 732 739** (UltraViewer would not connect
on 2026-09-05). Someone at the office has to accept the prompt, or the owner
enters the unattended-access password himself. Full machine facts are in the
memory note `office-host-access-facts`, and the load-bearing ones are repeated in
§5 below.

## 5. Traps that cost time today

- **Win+R is not forwarded by AnyDesk.** It opens Run on the LOCAL machine. A
  command nearly went to the wrong computer. Use the remote taskbar's search box;
  the remote is Windows 10 and the local is Windows 11, and the two taskbars sit a
  few pixels apart on screen — zoom before clicking.
- **Type in ~12-character chunks** through AnyDesk and UltraViewer, and verify the
  line before Return. The clipboard fast path replays the PREVIOUS command.
- **A new `workflow_dispatch` cannot be dispatched from its branch** — GitHub
  answers `HTTP 404: workflow not found on the default branch` whatever `--ref`
  says. Merge it, then dispatch immediately. Editing an EXISTING workflow's script
  is the case a branch dispatch does cover. (`docs/bugs/0637`)
- **`scm.mfg_sales_orders.status` is an ENUM.** `upper(status)` throws; cast to
  text. The check died AFTER printing one correct-looking section, which reads
  like a whole answer.
- **`setup.json` on the host points at a dead address** (`192.168.1.198\A2006`).
  Do not edit it — it belongs to the Inistate connector, still running. Pass
  `-Server '.\A2006' -Book 'AED_HOUZS'` to `deploy-on-host.ps1`.
- **The AcSyncService IS reachable by IP** over ZeroTier with a
  `Host: localhost:8900` header (403 = the service, asking for its key); a plain
  request gets 400 from `http.sys`. The tunnel `autocount.houzscentury.com` is
  alive and answers 401 without the key. Neither has a bulk-export route.

## 7. Rules that apply to every step of this

- **Dry/plan first, read the notice numbers, then apply, then re-read
  independently.** Never delete data. A line a person has touched is never
  overwritten.
- **Never accept a credential through chat**, never echo one, never write one into
  a file. The owner puts it into the tool that needs it.
- Public repo, public Actions logs: print counts, document numbers and classified
  reasons — **never** a customer, an item code, an address or an amount.
- Label every claim to the owner **PROVEN / LIKELY / UNKNOWN**, and say it in
  白话文 — business effect first, identifiers last.
