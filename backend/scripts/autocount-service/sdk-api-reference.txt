host (37 DLLs), not from documentation. Keep this next to AcSyncService.cs:
the SDK has no published reference, so this file IS the reference, and the next
person to touch the service should check a signature here before guessing.

Note the dump was taken with BindingFlags.DeclaredOnly, so inherited members
(notably InvoicingCommonCommand.CancelDocument and the document Save()) do not
repeat under each subclass.
