# 拆价提案(三条规则 + 两个待确认)

你说的规则:大件一定拆开 —— 两位躺 = 1A(R)+1A(R)、三位躺 = 1A(R)+2A、两位无扶手 = 1NA+1NA。
我核对了全部 174 行整件报价,发现**表上其实已经有单件价**,所以大部分不用拆价:

## 规则 1:2NA / 3NA / 2(no arm) —— 不用拆,直接用表上 1NA 单件价

- Hookka / Armani / Dorsettloft:2NA 价 = 正好 1NA × 2(93 行全验证过)。2NA 行忽略,1NA 单价已在导入计划里。
- THL:它的 `2(no arm)` 是打包优惠价(比单件×2 便宜,例:2376 60cm 打包 RM800,单件 RM460×2=RM920)。**成本按单件 RM460 记**,打包折扣留档。
- 没有单件参考价的 19 行(主要 Red Sofa)→ 用均分(表上无更好依据)。

## 规则 2:Todern recliner —— 1R 行就是 1A(R) 单件价

- TD 表的 `1R`(RM500/550/920)= 一个位一个扶手的躺件,左右同价 → 直接当 1A(R)(LHF)/(RHF) 导入(已进计划)。
- `2RR` = 1R×2 打包(RM950 vs 1000,打包便宜 RM50)→ 忽略,成本按单件。

## 待确认 A:3RR 的 2A 怎么定价?

- BS22/BS30 `3RR` RM1,760 = 1A(R) + 2A。1A(R) 表上有 RM920 → **2A = 1760 − 920 = RM840**,这样定可以吗?
